# Kaynakça

**Her yeni kaynak kullanıldığında buraya eklenir.** Web kaynakları için erişim tarihi yazılır. Raporda metin içinde [1], [2] biçiminde atıf yapılır.

## Kitaplar ve akademik kaynaklar
1. Sommerville, I. (2016). *Software Engineering* (10th ed.). Pearson. — Gereksinim mühendisliği, fonksiyonel/fonksiyonel olmayan gereksinimler, test stratejisi.
2. Gamma, E., Helm, R., Johnson, R., & Vlissides, J. (1994). *Design Patterns: Elements of Reusable Object-Oriented Software*. Addison-Wesley. — Command tasarım deseni (test adımları).
3. Cohn, M. (2004). *User Stories Applied: For Agile Software Development*. Addison-Wesley. — Kullanıcı hikâyesi kalıbı.
4. Cohn, M. (2009). *Succeeding with Agile: Software Development Using Scrum*. Addison-Wesley. — Test piramidi (birim / entegrasyon / uçtan uca test dengesi).
5. Clegg, D., & Barker, R. (1994). *Case Method Fast-Track: A RAD Approach*. Addison-Wesley. — MoSCoW önceliklendirme yöntemi.
6. Fowler, M. (2003). *UML Distilled: A Brief Guide to the Standard Object Modeling Language* (3rd ed.). Addison-Wesley. — Use case, sınıf ve sequence diyagramları.
7. North, D. (2006). *Introducing BDD*. https://dannorth.net/introducing-bdd/ — Kabul kriterlerinde Given–When–Then kalıbı.
8. Fowler, M. (2011). *Eradicating Non-Determinism in Tests*. https://martinfowler.com/articles/nonDeterminism.html — Kararsız (flaky) testler ve sabit beklemelerin sorunları.
